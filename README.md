# FITNESS FUEL — English version

This is a polished front-end version inspired by the requested dark/red fitness-magazine design.

Included:
- English navigation and copy
- Large fitness hero section
- hamburger menu with all articles
- article cards
- categories
- newsletter subscription UI
- login modal
- responsive mobile layout
- social-proof and statistics sections

To turn this into the full production site, connect the forms/articles/authentication to Supabase (or another backend) and replace the demo article data in `app.js`.
